# ESP32 Arduino-IDF Template

ESP-IDF template project that integrates Arduino as a component for ESP32 microcontroller development. Combines ESP-IDF's advanced capabilities with Arduino's simplicity.

## Key Features

- **Hybrid Framework**: ESP-IDF + Arduino component integration
- **LED Blink Example**: Ready-to-run demonstration (GPIO2)
- **Kiro IDE Optimized**: Pre-configured development environment
- **Docker Support**: Consistent development environment

## Target Hardware

- ESP32 family (ESP32, ESP32-S2, ESP32-S3, ESP32-C3)
- Any ESP32 development board
- Default LED: GPIO2 (configurable)

## Use Cases

- IoT device prototyping
- Learning ESP32 development  
- Arduino + ESP-IDF hybrid projects
- Educational projects
