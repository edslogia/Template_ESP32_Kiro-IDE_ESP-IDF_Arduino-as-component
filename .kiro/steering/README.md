# Steering Documentation Organization

This directory contains Kiro IDE steering files that provide context and guidance for AI assistance.

## File Organization

### Core Information

- **`product.md`** - Project overview and key features
- **`tech.md`** - Technology stack and versions
- **`structure.md`** - Project directory structure and file organization

### Development Guides

- **`arduino-integration.md`** - Arduino + ESP-IDF integration specifics
- **`cpp-best-practices.md`** - C++ coding standards and conventions
- **`commands.md`** - Command reference for common tasks
- **`personalization.md`** - User personalization preferences and AI behavior configuration

### Problem Solving

- **`troubleshooting.md`** - Common errors and solutions

## Design Principles

1. **No Redundancy**: Commands and version info are centralized
2. **Cross-References**: Files reference each other to avoid duplication
3. **Focused Content**: Each file has a specific, well-defined purpose
4. **Practical**: Emphasis on actionable information over theory

## Usage

- Kiro automatically includes these files as context
- Commands are centralized in `commands.md`
- Cross-references prevent information duplication
- Each file serves a specific role in the development workflow
